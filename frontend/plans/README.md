## Findings considered and not turned into plans

- **`outboxStateProvider` polls a COUNT query every 3s forever**
  (`lib/providers/outbox_provider.dart:108-117`), even when idle/online/empty.
  Minor battery/CPU; could be driven by Drift table-watch + the connectivity
  stream instead of `Stream.periodic`. Low impact, medium effort — deferred.
  Revisit if battery profiling flags it.
- **True reachability probe (health-ping)**: `ConnectivityService.isOnline()`
  trusts the OS interface state, so captive portals / dead uplinks read as
  online. A proactive HEAD-ping would be more honest but costs a request and is
  a judgment call. Plan 001 removes the *user-visible harm* (writes no longer
  hang 30s on such links) without a probe; banner honesty on captive portals is
  partially addressed once 003 can distinguish network-failed drains. A full
  probe is deferred as a product decision.
