- **Recurring-expense cron double-firing**: the repo tx guards with `WHERE id = $2 AND is_active = true AND next_due = $3` and rolls back on zero rows affected — adequate idempotency for this deployment shape.
- **`fromJson` crashes on missing required fields** (Flutter models): fail-fast on schema drift is a defensible convention; not worth a sweep.
- **Go / Firebase dependency lag**: routine minor-version drift, no known security driver; revisit on a normal upgrade cadence.

- **Intelligence dashboard hardening** (output-path validation in `runner.py`, unbounded file reads in `dashboard_server.py`): local, single-operator tooling with config-controlled inputs; low real-world exposure. Revisit if the dashboard is ever exposed beyond localhost.
